# 새소망 2차 전용 자산

- 생성일: 재현 가능한 script 출력(시간값 미기록)
- 현재 `/v3` 화면은 hero, Intro, 서비스 카드 3장의 승인 사진 5개만 각각 한 번 렌더링합니다. 사진은 승인된 기존 자산 또는 블로그 원본이며, 실제 직원 또는 센터 사진이라고 주장하지 않습니다.
- 프로젝트 고유 SVG 도해 9개는 자산 catalog와 이전 구성 재현을 위해 보관합니다. 현재 `/v3` 화면에서는 요청하거나 렌더링하지 않습니다.
- 블로그 원본 2개는 `assets/v3/saesomang/source/`에 보관하며 사용자 재사용 권한 확인일은 2026-10-15입니다. 기존 승인 사진 3개의 확인일은 2026-10-13입니다.
- 사진 출력은 원본 crop보다 크게 만들지 않습니다. `mission`은 손을 맞잡은 장면 전체 비율을 보존합니다.
- 원본 SHA-256, 권한 근거, crop, 실제 차원, 바이트는 `assets-manifest.json`에 있습니다.
- 자산 catalog 전송 예산 2.5MB에는 WebP 5개, 보관 SVG 9개, OG가 포함됩니다. 현재 화면 요청은 활성 WebP 5개와 필요한 브랜드 자산으로 한정됩니다. 제작 원본 PNG는 별도입니다.
